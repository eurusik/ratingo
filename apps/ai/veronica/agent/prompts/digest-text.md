Поверни лише JSON такої форми:

{"headline": "...", "actions": [{"id": "...", "text": "..."}], "interesting": "..."}

- headline: один короткий рядок з вердиктом дня, до 120 символів.
- actions: для кожного пункту з рівнем action перепиши поле advice живою мовою: що саме зробити. Збережи значення id без змін. Не додавай пунктів, яких немає в даних.
- interesting: необов'язковий один рядок про те, що змінилося порівняно з минулим тижнем, спираючись лише на поле trends.
- Жодних цифр у жодному полі.
